# notslowapi

Home of `notsoslow`, a fork of FastAPI that is being made faster, measured layer by layer.

- `vendor/fastapi`: the fork (Python package `notsoslow`), git subtree of github.com/4thel00z/fastapi
- `vendor/starlette`: git subtree of github.com/4thel00z/starlette
- `bench/`: the benchmark ladder (`uv run python -m bench.run`) and `bench/baseline/` with the numbers before any change
