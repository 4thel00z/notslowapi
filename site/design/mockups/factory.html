Method

Every change was measured before and after on a ladder of ASGI rungs, with native sampling from sample(1) and pyinstrument. Runs alternate after, before, after to reject noise. The numbers and the profiles are committed under bench/baseline.

How it got faster

Parameters without introspection

Parameter extraction stopped introspecting type annotations on every request.

request path

A solver that skips unasked work

The dependency solver skips what no endpoint asked for: the throwaway Response, unused query and cookie parsing.

dependencies

Layers only where a route needs them

Per-request exit stacks and middleware layers exist only when a route needs them.

middleware

Routes matched once

Routes reached via include_router are matched once, not twice, and static paths are indexed.

routing

One exception layer, one frame

One exception-handling layer instead of three, and one frame from router to handler.

call stack

Direct encoding and parsing

JSON encoding and query-string parsing run directly, without stdlib wrapper layers.

serialization

Deploy

granian recommended

Serve it right

Use granian

The measured 8.7 us/req on a plain route is granian on uvloop, one worker on one core.

granian --interface asgi --workers 1 --loop uvloop myapp:app

On uvicorn

Still 1.8x on the plain route. Pass these three flags.

uvicorn myapp:app --no-proxy-headers --no-server-header --no-date-header

Limits

  • The numbers are single-core. Multi-core scaling needs a separate client machine.
  • Code importing starlette.* directly gets upstream Starlette, not the vendored copy.

Questions

three, short

Before you switch

Is it really drop-in?

Yes. notslowapi is a fork of FastAPI 0.141 with the same API and the same test suite, 4,489 tests. Change from fastapi import FastAPI to from notslowapi import FastAPI and run the app you already have.

What happens to Starlette?

Starlette 1.6 is vendored and tuned inside notslowapi; nothing is installed under the starlette name. Code that imports starlette.* directly gets upstream Starlette.

Do I have to run granian?

No. On uvicorn notslowapi is 1.8x FastAPI on the plain route; pass --no-proxy-headers --no-server-header --no-date-header. Granian on uvloop is where the 3.6x comes from.
