It stops doing work nobody asked for.

Parameter extraction no longer introspects type annotations on every request.

The dependency solver skips what your endpoint never asked for: the throwaway Response, query and cookie parsing that nothing reads.

Per-request exit stacks and middleware layers exist only when a route needs them.

2.5x on an int path + str query param route, both on uvicorn: 57.0 down to 22.4 µs per request.

Fewer layers between the socket and your function.

Routes reached through include_router are matched once, not twice, and static paths are indexed.

One exception-handling layer instead of three. One frame from router to handler.

JSON is encoded and query strings are parsed directly, without stdlib wrapper layers. Starlette itself is vendored and tuned.

3.5x on 50 routes via include_router, both on uvicorn: 92.2 down to 26.3 µs per request.

Switch in a minute.

  1. 1 InstallThe granian extra pulls in the server the top numbers use. uv add notslowapi[granian]
  2. 2 Change one importEverything else in your app stays as it is. from notslowapi import FastAPI
  3. 3 Run itOne worker on one core is what every number on this page measures. granian --interface asgi --workers 1 --loop uvloop myapp:app

Nothing is installed under the starlette name. Code that imports starlette.* directly keeps getting upstream Starlette, not the vendored, tuned copy.

Deploy on granian.

granian with uvloop is where the 3.6x comes from. Staying on uvicorn still gives you 1.8x on the plain route; pass the flags below so it stops adding headers to every response.

Questions

Is it really drop-in?

Yes. The public API is FastAPI's, and the fork passes FastAPI's own test suite, all 4,489 tests. Change from fastapi import FastAPI to from notslowapi import FastAPI and keep the rest. The one edge: code that imports starlette.* directly gets upstream Starlette, because nothing is installed under the starlette name.

Are these numbers multi-core?

No. Everything on this page is one core on an Apple M3 Pro with Python 3.13, 64 keep-alive connections, median of three 5-second runs. Measuring multi-core scaling honestly needs a separate client machine, so it is not claimed here.

Do I need granian?

No. On uvicorn the plain route goes from 31.2 to 17.1 µs per request, 1.8x. Run it with --no-proxy-headers --no-server-header --no-date-header. granian with uvloop is where 3.6x comes from, and it is what we recommend for deployment.
