notslowapi logo directions

Four directions for the notslowapi mark, a FastAPI fork with the same code and 3.6x the throughput per core. Every file is inline SVG, viewBox based, no external fonts or requests. Ink is currentColor with a root color="#111827" attribute so the standalone files render dark on light; the dark boards below only override that colour. Each direction carries one accent, stated as hex next to its title.

1

Strike wordmark

#E8552B

The whole joke in one line: geometric monoline letterforms built from paths, with slow compressed to 80% width and struck through in signal orange, so the name reads as not~~slow~~api before anyone parses the letters.
